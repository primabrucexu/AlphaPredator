## What

F005.1 将已经存在的自选股、标签和后台任务能力接入 MCP，使 Hermes 等客户端能够：

1. 管理自选股和标签；
2. 创建已明确允许的后台任务，并立即获得公开 UUID；
3. 根据 UUID 主动查询任务进度和分页获取详细输出；
4. 在任务结束后，由 AlphaPredator 的 Hermes 插件把任务级结果异步注入发起任务的 Hermes Session。

异步等待不得阻塞 Hermes Session。任务执行期间，用户仍然可以在同一 Session 中继续交互。

### 非目标

- 不提供任意 `task_type` 的通用任务创建 Tool。
- 不接入已经暂时停用的韭研公社任务。
- 不提供任务取消、任务列表、阻塞等待、MCP Resource 或 MCP Prompt。
- MCP 不读取或修改同花顺账号密码配置，也不直接调用 thsdk。
- MCP 不直接访问 DuckDB；日线更新仍由 F002 Worker 串行执行。
- 不修改 Hermes 核心代码和微信通道适配器。
- 本 Feature 只保证结果被注入 Hermes Session，不保证微信用户最终收到该消息。

## How

### 1. 业务复用边界

- 从现有 REST 路由中提取必要的自选股、标签和具体任务创建逻辑到 service 层。
- REST 与 MCP 只做输入输出适配，共用相同校验、事务和错误语义，不复制业务逻辑。
- MCP Tool 使用独立数据库 Session，并保证 Tool 返回前完成提交或回滚。
- MCP 继续复用 F005 的 FastMCP Server 和 `/api/mcp/` Streamable HTTP 入口。

### 2. 首批 Tool

#### 自选股与标签

| Tool | 主要输入 | 行为与返回 |
|---|---|---|
| `list_watchlist` | 无 | 返回自选股、股票名称和已关联标签 |
| `add_watchlist_stock` | `symbol` | 规范化代码后加入自选，返回新增自选股 |
| `remove_watchlist_stock` | `symbol` | 按股票代码移出自选并解除该股票的标签关联，保留全局标签，返回成功结果 |
| `list_tags` | 无 | 按当前顺序返回标签及股票数量 |
| `create_tag` | `name` | 创建标签，返回标签 |
| `rename_tag` | `tag_id`, `name` | 重命名标签，返回更新后的标签 |
| `delete_tag` | `tag_id` | 删除标签及其关联，保留自选股，返回成功结果 |
| `attach_tag_to_stock` | `symbol`, `tag_id` | 关联已有标签；股票不在自选时同时加入自选 |
| `detach_tag_from_stock` | `symbol`, `tag_id` | 解除股票与标签的关联，保留自选股和标签 |
| `reorder_tags` | `tag_ids` | 使用包含全部标签且不重复的 ID 列表更新顺序 |
| `reorder_tag_stocks` | `tag_id`, `symbols` | 使用包含标签内全部股票且不重复的代码列表更新顺序 |

#### 后台任务

| Tool | 主要输入 | 行为与返回 |
|---|---|---|
| `create_stock_directory_refresh_task` | 无 | 创建股票目录刷新任务，立即返回任务 UUID 和初始状态 |
| `create_market_daily_bars_update_task` | `mode: incremental \| full` | 创建日线更新任务，立即返回任务 UUID 和初始状态 |
| `retry_failed_market_daily_bars_task` | `task_uuid` | 对部分成功日线任务中的失败股票创建新任务，返回新 UUID |
| `get_task` | `task_uuid` | 返回任务状态、进度、任务级结果、错误和时间信息 |
| `get_task_output` | `task_uuid`, `page`, `page_size` | 分页返回子任务状态、进度、结果和错误 |

`page` 默认 1；`page_size` 默认 50，最大 100。任务创建 Tool 不等待任务完成。

### 3. 公开任务 UUID

- `Task.id` 继续作为 SQLite 内部主键和 `TaskItem.task_id` 外键，不改变现有内部关联。
- `Task` 新增非空、唯一、带索引的公开 UUID；新任务在创建时生成 UUID。
- 迁移为存量任务回填互不重复的 UUID，并提供迁移测试。
- MCP 任务 Tool 只接受和返回公开 UUID，不暴露整数 ID。
- 现有 REST API 保持整数 ID 兼容；REST 任务响应可增加 UUID，但不得破坏现有调用方。

### 4. 任务错误语义

- 参数格式错误、对象不存在、重复数据和任务前置条件不满足时，返回明确、可供 Agent 修正的 Tool 错误。
- 同类型排他更新任务已经处于等待或执行状态时，不创建重复任务；错误中返回现有任务 UUID。
- 股票目录为空时，日线更新明确提示先创建股票目录刷新任务。
- 查询不存在的 UUID 返回“任务不存在”，不得退化为内部整数 ID 查询。
- Worker 或外部数据失败时保留真实任务状态和错误，不生成伪造结果。

### 5. Hermes 异步结果插件

插件暂时和 AlphaPredator 一起维护，但作为独立 Python 包管理：

```text
integrations/hermes/alphapredator-task-notifier/
├── pyproject.toml
├── README.md
├── src/alphapredator_task_notifier/
└── tests/
```

- 使用独立版本号、`src` 布局和 `hermes_agent.plugins` entry point；支持构建 wheel 和 editable install。
- 插件不得导入 AlphaPredator 后端包；通过已注册的 MCP Tool 查询任务。
- 运行时尽量只依赖 Python 标准库，避免改变 Hermes 现有依赖解析结果。
- `post_tool_call` Hook 处理本 Feature 当前 4 个任务创建 Tool，从返回值提取 AlphaPredator 任务 UUID，并记录当前 Hermes `session_id`。
- UUID、Session 映射、轮询状态和注入状态持久化到 Hermes 的插件私有数据目录，不写入项目仓库。
- 后台轮询不占用对话执行链；Hermes 重启后继续处理尚未终结或尚未注入的记录。
- 任务进入终态后，插件注入任务 UUID、终态、任务级 `result`、错误和失败/跳过摘要；不把全部子任务明细一次性注入上下文，用户可通过 `get_task_output` 分页查询。
- 使用 Hermes 自带 Session API 向原 Session 注入结果；API 只监听本机，API Key 从环境变量读取，不提交到仓库。
- Session 忙碌或暂时不可用时保留待注入记录并重试；成功后记录完成状态，避免重复注入。
- 插件只负责 Session 注入，不判断微信通道是否成功向最终用户投递。

## Risk

| 风险 | 解决 |
|---|---|
| 全市场任务子项很多，完整注入会污染 Session 上下文 | 自动注入仅包含任务级结果和摘要，详细子项由 Tool 分页查询 |
| Hermes 或 AlphaPredator 重启导致映射丢失 | 插件在仓库外持久化映射和注入状态，启动时恢复 |
| Session 忙碌导致注入失败或重复 | 失败保留待处理状态并退避重试，成功后幂等标记 |
| Hermes 环境依赖冲突 | 插件作为独立包管理并保持最小运行依赖 |
| UUID 改造破坏存量任务 | 保留整数主外键，使用显式迁移、回填和兼容性测试 |
