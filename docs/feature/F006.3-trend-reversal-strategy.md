## What

### 已确认需求

- 第一版选股范围为沪深主板、执行时当前非 ST，不设置市值条件。
- 使用前复权日线收盘价计算 MACD，固定参数为 `(8, 17, 6)`，计算口径与项目现有 MACD 一致。
- revision 2 从 MACD 柱局部低点后的第一根起计算，连续三个有效日均不下降且第三日严格改善时首次入选；精确公式以 SR001 规则文档为准。
- revision 3 沿用 revision 2 的候选信号，仅在该信号对应交易仍待买入或持仓时作为当前机会；交易已全部结束的旧信号不再因原 MACD 序列延续而命中。
- MACD 使用 100 根有效日 K 预热；不足 100 根时使用上市以来全部数据继续计算并标记历史数据不足。
- 选股后从下一根日 K 开始按开盘价尝试买入；停牌或一字涨停时无限顺延至下一根可买入日 K。
- 买入信号一旦产生即锁定，等待期间的 MACD 变化不取消信号。
- 买入后的有效日 K 收盘盈利严格超过 5% 时，按当日收盘价卖出当前持仓 50%，每笔交易最多触发一次 TP1。
- MACD 连续两根红柱且后一根缩短时锁定 EX1，在下一根可卖出日 K 按开盘价卖出全部剩余持仓。
- 买入日不检查盈亏；从下一根有效日 K 开始，开盘或盘中相对原始买入开盘价亏损达到 5% 时，SL1 卖出全部剩余持仓。
- EX1 与 TP1 同时满足时放弃 TP1 并执行 EX1；EX1 先触发后不等待或切换为 SL1。
- TP1 按 SR001 的收盘价历史数据模型成交，不受一字跌停限制；EX1 或已锁定的 SL1 遇停牌或一字跌停时无限顺延至下一根可卖出日 K。
- 同一只股票最多有一笔活动交易；等待买入、持仓或等待卖出期间的新信号全部忽略。
- 收益只按股票买卖价格变化计算，不计佣金、印花税、滑点或其他费用。
- SR001 同时支持 F006.2 的个股回测和全市场组合回测。
- “模式选股”页面固定使用 SR001 revision 3 和规则固定参数，显式提供默认全市场和指定股票两种范围；命中后自动执行历史个股回测，创建后进入专用详情查看信号依据、统计和交易结果。
- SR001 的独立选股、个股回测和模式选股结果摘要均展示任务持久化的实际规则版本，使历史 revision 1、2 结果与 revision 3 新结果可以明确区分。

规则的精确公式、编号、边界和验证样例只在 SR001 文档维护；本 Feature 负责实现接入和用户可见验收，不复制第二份完整公式。

## How

- F006.3 注册 SR001 的内置 Evaluator 和回测交易策略，实际规则口径以 SR001 当前确认版本为准。
- 指定日期选股通过 F006.1 执行；历史个股和全市场模拟通过 F006.2 执行。
- Web 和 MCP 不直接读取 DuckDB；全部指标、选股和回测计算由独立 Worker 完成。
- F006.3 首版实现必须绑定 SR001 revision 1；影响结果的规则变化必须增加规则版本，并由任务和结果记录实际版本。

## Implementation

- SR001 revision 1、2、3 位于 `backend/app/screening/rules/sr001.py`，固定参数不能由任务覆盖；revision 1、2 保留用于历史任务，页面新任务使用 revision 3。
- 生产注册同时提供通用选股 Evaluator 和个股回测会话；Web 负责创建任务，独立 Worker 读取 DuckDB 并执行。
- 个股回测会话使用有状态 MACD 累加器：首次处理已有预热历史，后续每根 K 线只递推一次；revision 1 保留最近三根 MACD 点，revision 2、3 保留最近五根。revision 3 的模式选股复用生命周期判定时已经完成的回测结果，避免重复计算。
- 自动化测试覆盖选中、未选中、历史数据不足、元数据异常、买入顺延、TP1、EX1、SL1、退出优先级、一字跌停顺延和重复信号。
- `/screening` 默认扫描当前全部沪深主板非 ST 股票，切换到“指定股票”后执行小范围扫描；revision 3 对 C1 候选复用历史回测判断 L1。结果主表展示保留 3 位小数的 MACD 信号窗口、当前状态和历史统计，不重复展示所有命中行必然通过的 U1/U2/C1/L1 标签；完整 evidence 继续持久化。
- 页面、详情路由和活动数量统一按调度策略分类；SR001 选股和回测作为 `COMPUTE` 自动进入“模式选股”，旧任务详情链接自动跳转至对应页面。
- SR001 MCP 创建 Tool 已改为默认使用当前最新 revision，F008 报告 Tool 已实现但尚未完成真实 Hermes 验证。F006.2 全市场组合模式也尚未实现，因此本 Feature 保持“部分完成”。

## Risk

| 风险 | 解决 |
|---|---|
| Feature 与 SR001 重复维护规则公式 | 公式、参数和边界只在 SR001 维护，Feature 只引用并验收 |
| 当前非 ST 口径使历史回测随执行时状态变化 | 按已确认口径执行，不擅自替换为历史 ST 状态 |
| 简化一字板口径误判单一价格成交 | 按 SR001 已确认口径执行并在结果中保留 OHLC 判定依据 |
| 无限顺延导致信号在很久以后成交 | 这是已确认交易规则；结果必须显示 T 日、B 日和等待长度 |
