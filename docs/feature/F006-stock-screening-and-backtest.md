## What

F006 是选股规则、规则执行和历史回测能力的总览，不直接承载具体实现：

- F006.1 负责在指定日期按已注册规则判断股票是否入选。
- F006.2 负责在历史区间内模拟规则的买入、持有和卖出。
- F006.3 负责接入第一条具体规则 `SR001 趋势反转`。
- F006.4 负责把指定日期信号扫描与命中股票的历史个股回测组合成一次用户操作和一份可读结果。
- 具体规则公式、参数和交易口径统一记录在 `docs/screening-rules/`，子 Feature 不重复维护另一份完整规则定义。

## How

```text
F003 历史行情
      │
      ▼
F006.1 选股规则执行器
      ├── 指定日期选股
      └── 向 F006.2 提供确定性 Rule Evaluator
                   │
                   ▼
          F006.2 历史回测引擎
                   │
                   ▼
          个股回测 / 全市场组合回测

F006.4 模式选股与历史回测分析
      ├── 复用 F006.1 判断扫描日信号
      └── 仅对命中股票复用 F006.2 个股回测

F006.3 趋势反转战法
      └── SR001 规则定义与接入验收
```

F006.1 和 F006.2 的行情读取与计算均遵守 F003 的 Worker 独占 DuckDB 边界；Web 和 MCP 只创建任务并读取 SQLite 中的任务及结果。
