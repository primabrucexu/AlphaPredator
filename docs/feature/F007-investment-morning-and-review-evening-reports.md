## What

F007 为用户提供每日投资信息汇总。报告由 Agent 定时生成并主动推送，分为投资早报和复盘晚报。

### 投资早报

投资早报包含：

1. 外围市场动向：
   - 隔夜美股表现；
   - 早报生成时，日本、韩国股市的当日动向；
   - 原油、黄金等重要期货品种的动向。
2. 公司公告。
3. AlphaPredator 选股规则的信号提示。

外围市场数据需要标明对应的市场日期和数据时间点，区分已经收盘的隔夜行情与早报生成时的当日行情。

### 复盘晚报

复盘晚报包含市场情绪和短线情绪两部分。

#### 市场情绪

1. 沪深两市成交额；
2. 上证指数、深证成指、创业板指、科创 50 的涨跌情况；
3. 当日上涨家数、下跌家数，以及核心权重股的涨跌情况；
4. 当日涨幅前 5 和跌幅前 5 的板块。

#### 短线情绪

1. 连板梯队情况，从二板开始展示，不统计首板；
2. 近期涨幅过高股票的当日涨跌情况。

### 当前不包含

- 不提供持仓股票的处理建议。
- 不包含规则执行性能 Benchmark；原有 F007 Benchmark 设想不再保留。

## How

当前处于需求设计阶段。本阶段只确认报告的使用方式和内容组成，不提前限定数据源、生成时间、推送渠道及具体计算口径。

后续设计需要逐项确认：

- 早报和晚报的生成、推送时间，以及非交易日处理方式；
- Agent 的推送渠道和失败后的处理方式；
- 公司公告覆盖的股票范围、公告类型和筛选口径；
- 选股信号覆盖的规则范围、T 日（信号触发日）和展示内容；
- 核心权重股的范围或选取规则；
- 板块采用行业板块、概念板块，还是同时包含两者；
- “近期涨幅过高”的观察周期和判定标准；
- 外围市场、公告、A 股市场及短线情绪数据的数据源；
- 数据延迟、缺失、不同市场休市时的报告表达方式。

上述事项确认后，再补充具体方案和实施验收标准。

## Acceptance Criteria

- [ ] AC1: Agent 能够按照最终确认的时间安排自动生成并主动推送投资早报和复盘晚报。
- [ ] AC2: 投资早报覆盖外围市场动向、公司公告和选股规则信号提示。
- [ ] AC3: 外围市场动向覆盖隔夜美股、报告生成时的当日日韩股市，以及原油、黄金等重要期货，并标明数据时间点。
- [ ] AC4: 复盘晚报的市场情绪覆盖两市成交额、四个指定指数、涨跌家数、核心权重股及涨跌幅前 5 板块。
- [ ] AC5: 复盘晚报的短线情绪展示二板及以上连板梯队和近期涨幅过高股票的当日涨跌情况，不包含首板。
- [ ] AC6: 报告不提供持仓股票处理建议。
- [ ] AC7: 所有待确认口径在进入实现前形成明确设计和可验证标准。

## Risk

| 风险 | 解决 |
|---|---|
| 不同市场的交易日期、时区和休市安排不一致 | 报告展示市场日期和数据时间点，具体休市口径在方案阶段确认 |
| “核心权重股”“板块”“近期涨幅过高”等定义不明确 | 实现前分别确认名单、分类体系和计算口径 |
| 外部行情或公告数据存在延迟、缺失 | 方案阶段确认数据源、时效要求和缺失时的明确提示方式，禁止伪造数据 |
| 自动推送依赖 Agent 入口和目标渠道 | 后续确认推送渠道、调度方式和失败处理，再进入实现 |
