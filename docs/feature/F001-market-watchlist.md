# F001: 行情、自选股与涨停历史

| 日期 | 事件 |

## What

提供一个个人使用的 A 股行情 Demo：通过代码、名称或拼音搜索股票，查看最新行情、最近 250 个交易日日 K、成交量、成交额和可调参数的 MA、EXPMA、MACD、KDJ；管理自选分组和个股标签；在个股详情查看最近 10 条韭研公社涨停历史。

## How

- FastAPI + SQLAlchemy + SQLite 提供 API 和本地用户数据持久化。
- `MarketDataProvider` 隔离业务层与 `thsdk`，统一使用 `600519.SH` 格式。
- `thsdk` 保持单客户端串行访问，FastAPI 同步路由在线程池运行。
- 股票目录保存名称与拼音索引；行情和日 K 不落库。
- 技术指标由前端根据日 K 即时计算，参数可直接调整。
- 韭研公社使用本地 SESSION，按用户选择的日期范围手动同步。

## Risk

| 风险 | 解决 |
|------|------|
| thsdk 是第三方原生库封装 | 锁定版本并隔离在 Provider；生产使用前确认账号和数据授权 |
| thsdk 并发安全未明确 | 第一版单进程、同一客户端加锁串行调用 |
| 韭研 SESSION 会失效 | 设置页提供更新和验证入口，失败时显示真实错误 |
| 新股、ST 等特殊涨跌停规则复杂 | 仅在可以可靠判断时标记；后续补充上市日期规则 |
