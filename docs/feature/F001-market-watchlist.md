## What

> 当前状态：韭研公社相关页面、API 与同步能力暂时停用。下述韭研内容保留为已完成的历史设计，不代表当前可用；SQLite 中已有凭据和涨停记录不删除。

提供一个亮色主题的个人 A 股行情 Demo：通过代码、名称或拼音搜索股票，查看最新行情和可向前自动加载的前复权日 K、成交量、成交额以及可调参数的 MA、EXPMA、MACD、KDJ；管理自选股和个股标签，并按标签自动形成自选分组；在个股详情查看最近 10 条韭研公社涨停历史。

## How

- FastAPI + SQLAlchemy + SQLite 提供 API 和本地用户数据持久化。
- `MarketDataProvider` 隔离业务层与 `thsdk`，统一使用 `600519.SH` 格式。
- `thsdk` 保持单客户端串行访问，FastAPI 同步路由在线程池运行。
- 股票目录保存名称与拼音索引；行情和日 K 不落库。
- `thsdk` 日 K 统一使用前复权；首次取最近 250 个交易日，时间范围移动到左端时按年加载更早数据。
- 图表固定为 K 线主图、成交量/成交额副图、MACD/KDJ 副图，指标由前端即时计算且参数可调整。
- 技术指标曲线和坐标轴数值显示两位小数；图表指标选择及参数保存在浏览器 `localStorage`，刷新后恢复。
- 成交量/成交额副图隐藏纵轴数字；MACD 副图隐藏纵轴刻度和普通网格线，只保留水平 0 轴。
- 日期轴位于 K 线主图下方，按约 20 个交易日的间隔降低日期标签密度，副图不重复显示日期。
- 鼠标悬浮框只展示当日最高、最低、开盘、收盘和涨幅；其他指标当前值随十字光标更新，并显示在对应图层左上角。
- 自选只记录股票；标签动态形成自选分组，多标签股票重复展示，无标签股票进入“未分类”。
- 左侧第一列固定承载功能导航；进入“我的自选”时才在独立的第二列展示标签列表，标签支持搜索、独立滚动、拖动排序、重命名和全局删除，点击标签筛选自选页面。
- 个股标签输入按名称前缀提示尚未关联的已有标签，同时允许直接输入新名称创建并关联；手动添加标签时自动把该股票加入自选；自选页第二列也可独立新建标签。
- 每个自选标签分组提供股票快速添加入口，可按代码、名称或拼音搜索；选择后自动加入自选并关联当前标签。
- 每个标签分组内的股票可独立拖动排序，顺序保存在标签关联上；同一股票在不同标签中的位置互不影响。
- 启动时把旧版非默认自选分组转换成标签、合并重复自选，并保留 `legacy_*` 表用于恢复。
- 韭研公社通过 Playwright 弹出本机浏览器登录并自动捕获 SESSION，再按用户选择的日期范围逐日手动同步，不限制范围跨度。

## Risk

| 风险 | 解决 |
|------|------|
| thsdk 是第三方原生库封装 | 锁定版本并隔离在 Provider；生产使用前确认账号和数据授权 |
| thsdk 并发安全未明确 | 第一版单进程、同一客户端加锁串行调用 |
| 韭研 SESSION 会失效 | 设置页支持重新弹窗登录并自动校验，失败时显示真实错误 |
| 新股、ST 等特殊涨跌停规则复杂 | 仅在可以可靠判断时标记；后续补充上市日期规则 |
