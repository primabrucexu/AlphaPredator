## 模板说明

- 一份文档表示一条可以独立执行的完整选股规则，不为单个指标或原子条件单独建立规则文档。
- 编号统一使用：`U` 表示选股范围，`I` 表示指标或事件，`C` 表示选股信号，`E` 表示排除条件，`B` 表示买入，`TP` 表示止盈，`SL` 表示止损，`EX` 表示技术退出。
- 规则不需要某类退出条件时明确写“不适用”，不要删除整体结构后让执行器猜测。
- 选股范围、指标、选股判定和回测交易口径各自独立，不得互相替代。
- 有效日 K、预热、日期计数、信号锁定、T+1、部分卖出、退出优先级和无法成交处理必须有明确口径。
- 规则公式、默认参数、选股范围、买卖条件或其他影响结果的变化必须增加规则版本；纯文案修正不增加版本。
- 一次执行使用的实际参数变化不增加规则版本，但必须记录在任务或回测结果中。
- 规则文档不由运行时直接解释为代码；实现只能使用已注册的确定性 Evaluator，除非未来 Feature 明确引入受限 DSL。
- 每个规则至少提供选中、未选中、历史数据不足、行情数据异常和一组完整回测样例，并在能力实现时转化为自动化测试。
- 在规则文档中定义回测口径，不代表来源 Feature 已经批准或实现回测引擎；实现范围仍以对应 Feature 为准。
