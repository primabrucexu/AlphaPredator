- 完整计算公式或明确引用的统一指标口径。
- 指标预热所需的最少数据量。
- 时间偏移含义，例如 `I2[t]` 与 `I2[t-1]`。

- C2：{条件定义}。

### 排除条件

- E1：{排除条件；如无则写“无”}。

```text

```

最终判定必须明确各条件之间的 `AND`、`OR`、`NOT` 和优先级，不得使用“近期”“明显”“走强”等未量化描述直接参与计算。

## 模板说明

- 一份文档表示一条可以独立执行的完整选股规则，不为单个指标或原子条件单独建立规则文档。
- 编号统一使用：`U` 表示选股范围条件，`I` 表示指标或事件，`C` 表示选股信号，`E` 表示排除条件，`B` 表示回测买入条件，`TP` 表示止盈，`SL` 表示止损，`EX` 表示技术退出。
- 选股范围负责确定股票是否具备候选资格；指标及参数负责定义计算口径；选股判定负责说明如何组合条件得到最终结果，三者不得互相替代。
- 规则公式、默认参数、选股范围、回测买卖条件或其他影响结果的口径变化必须增加规则版本；纯文案修正不增加版本。
- 一次执行使用的实际参数变化不增加规则版本，但必须记录在任务或回测结果中。
- 规则文档不由运行时直接解释为代码；实现只能使用已注册的确定性 Evaluator，除非未来 Feature 明确引入受限 DSL。
- 每个规则至少提供选中、未选中、数据不足和一组回测样例，并在相应能力实现时转化为自动化测试。
- 在规则文档中定义回测口径，不代表来源 Feature 已经批准或实现回测能力；是否开发回测引擎仍以对应 Feature 的确认范围为准。
